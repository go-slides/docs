Galerie

Zwölf kleine Foliensätze, die jeweils eine Sache gut zeigen: Themes, Kinds, Vorlagen, HCL, Mathematik, Bilder, Code, Emoji, Übergänge und ein vollständiger Vortrag. Jeden davon können Sie im Playground öffnen.

Sie lesen die Dokumentation einer veralteten Version; ihr Inhalt ist möglicherweise nicht mehr korrekt. Zur neuesten Version.

Zwölf kleine Foliensätze aus dem Ordner examples/ von go-slides, die jeweils eine Sache gut zeigen. Die Vorschaubilder zeigen die erste Folie jedes Foliensatzes, von go-slides selbst beim Bau dieser Website gerendert; die CI baut jeden Foliensatz zu HTML und PDF, damit keiner kaputtgeht.

Open in the playground lädt den Foliensatz in Ihrem Browser, über einen Link, der nichts an einen Server sendet. Ein Foliensatz, der neben deck.md weitere Dateien hat (eine Kinds-Datei, eingebundene Teile, Bilder), passt nicht in einen Link: Laden Sie sein .zip herunter und importieren Sie es über das Dateifenster des Playgrounds, oder entpacken Sie es und bauen Sie es mit slides build --allow-local-files deck.md.

Die Bilder sind Original-SVGs der go-slides-Autoren, freigegeben unter CC0 1.0; die Foliensätze, die sie verwenden, weisen darauf hin.

# The default theme

A clean, light deck: black text on white, a blue accent, room to breathe.

---

## Headings, lists, quotes

- Level-one and level-two headings get a rule under them
- **Bold**, *italic*, `inline code` and [links](https://github.com/go-slides/slides)
- Lists nest:
  - like this
  - and this

> A quotation is set apart by a bar on its left.

---

## Tables and code

| Theme   | Feels like     | Best for           |
| ------- | -------------- | ------------------ |
| default | a clean page   | documentation      |
| gaia    | a warm poster  | talks              |
| uncover | a calm stage   | keynotes           |

```go
func main() {
	fmt.Println("hello, slides")
}
```

## Invert

`<!-- _class: invert -->` flips one slide to light-on-dark, whatever the
theme. Nothing else changes.

Warm paper, strong headings, a cover slide.

Gaia sets a heavy heading over a warm background, with a coloured band on the
left of ordinary slides.

- It reads well from the back of a room

The `lead` class centres a slide. Add `invert` for a dark one.

HCL front matter

4 Folien

The front matter in HCL2: expressions, functions and typed data, with the same directives as YAML.

Im Playground öffnen Quelle auf GitHub

deck.md
---hcl
theme    = "uncover"
paginate = true
title    = "HCL front matter"
description = "The front matter in HCL2: expressions, functions and typed data, with the same directives as YAML."

data = {
  company = "ACME"
  quarter = 3
  growth  = [4.2, 5.1, 6.8]
}

header = format("%s — Q%d review", data.company, data.quarter)
footer = "${upper(data.company)} · ${page()}/${total()}"

kind "chapter" {
  extends = "section"
  class   = ["invert"]
}
---

# {{ .company }} Q{{ .quarter }}

Front matter written in HCL, not YAML.

---

## Expressions and functions

The header and footer above are not text, they are **expressions**:

```hcl
header = format("%s — Q%d review", data.company, data.quarter)
footer = "${upper(data.company)} · ${page()}/${total()}"
```

`page()` and `total()` are go-slides' own; the rest is HCL's standard library.

---

<!-- _kind: chapter -->

# Typed data

Numbers stay numbers, lists stay lists.

---

## Quarterly growth

{{ range $i, $g := .growth }}- Month {{ add $i 1 }}: **{{ $g }} %**
{{ end }}

`slides expand` writes this front matter back as YAML, so Marp can read the
deck too.

---

# Math

`$…$` inline, `$$…$$` display. No JavaScript, no network.

---

## Inline

Einstein wrote $E = mc^2$, Euler $e^{i\pi} + 1 = 0$, and the roots of
$ax^2 + bx + c = 0$ are what the next slide is about.

A formula follows the text's size and sits on its baseline: $\alpha + \beta$,
$\sqrt{2}$, $x_{n+1}$, $\sum_{k=1}^{n} k$.

---

## The quadratic formula

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

Display formulas are centred and sized for the slide.

---

## Calculus and sums

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
\qquad
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
$$

---

## Matrices

$$
A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix},
\qquad
\det A = 1 \cdot 4 - 2 \cdot 3 = -2
$$

---

## Prices are not math

Following Marp Core's rules, a `$` followed by a space does not open a formula
and one followed by a digit does not close it: this costs $5 and that costs
$10, and both stay text.

# Code

Highlighting, line numbers and callouts.

---

## Highlighting

```go
package main

import "fmt"

func main() {
    for i := 1; i <= 3; i++ {
        fmt.Println("slide", i)
    }
}
```

Colours come from the theme, through highlight.js class names.

---

## Line numbers

```python {lineNumbers}
def fizzbuzz(n):
    for i in range(1, n + 1):
        if i % 15 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)
```

`{lineNumbers}` after the language. They are not copied with the code.

---

## Starting somewhere else

```js {lineNumbers=42}
export function clamp(x, lo, hi) {
  return Math.min(Math.max(x, lo), hi);
}
```

`{lineNumbers=42}` starts at 42, for a snippet that lives in the middle of a
file.

---

## Callouts

```go {lineNumbers}
func serve(addr string) error {
    mux := http.NewServeMux() // <1>
    mux.HandleFunc("/", home) // <2>
    return http.ListenAndServe(addr, mux) // <3>
}
```

1. A router of our own, not the global one.
2. Every request not matched elsewhere lands here.
3. Blocks until the server fails.

---

## Hover to connect

Point at a disc, or tab to it: its note lights up, and the other way round.

```sh
slides build deck.md # <1>
slides deck.md --pdf # <2>
```

1. Writes `deck.html`.
2. Writes `deck.pdf`, with vectors and selectable text.

## Measure it

The speed-up of a parallel build on $n$ cores, with a serial fraction $s$ of
the work, is bounded by

$$
S(n) = \frac{1}{s + \frac{1 - s}{n}}
$$

so even $s = 5\%$ caps it at $20\times$.

<!-- Amdahl's law. Do not derive it; point at the cap. -->
