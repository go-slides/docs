**Тип** (kind) — это именованный набор локальных директив: верхний и нижний
колонтитулы, нумерация, класс, фон. Слайд говорит, чем он является, — `title`,
`section`, — вместо того чтобы повторять, как он выглядит, а оформление
презентации меняется в одном месте.

## Использование типа {#using-a-kind}

```markdown
<!-- kind: section -->
# Part two

---

<!-- _kind: blank -->
![bg](photo.jpg)
```

- `kind:` действует как локальная директива: на этот слайд и следующие за ним.
- `_kind:` действует как точечная директива: только на этот слайд.
- При смене типа сначала **сбрасывается** то, что задал предыдущий тип, так что
  класс или колонтитул никогда не переходит из одного типа в другой.
- Директивы, записанные на самом слайде, **главнее** типа.

## Встроенные {#built-in}

| Тип | Задаёт |
| --- | --- |
| `title` | `class: lead`, без номера страницы, без верхнего и нижнего колонтитулов |
| `section` | `class: lead` |
| `content` | ничего: значения презентации по умолчанию |
| `blank` | без номера страницы, без верхнего и нижнего колонтитулов |

Любой из них можно переопределить.

## Определение типов {#defining-kinds}

Во front matter:

```yaml
---
marp: true
kinds:
  chapter:
    class: invert
    backgroundColor: "#1e1b4b"
    paginate: false
  quote:
    extends: blank
    class: quote
---
```

`extends` начинает тип с директив другого типа. Тип принимает локальные
директивы и `extends`.

## Общие типы {#sharing-kinds}

Типы команды стоит держать в одном файле, который называют все презентации:

```yaml
# kinds.yaml
chapter:
  class: invert
  paginate: false
```

```yaml
---
marp: true
kinds: kinds.yaml        # or a list of files
---
```

или `--kinds kinds.yaml` в командной строке, или `kinds:` в `slides.yaml`.
Порядок такой: встроенные типы, затем командная строка и файл конфигурации,
затем собственный `kinds:` презентации.

`slides kinds talk.md` перечисляет типы, которые может использовать презентация,
и что задаёт каждый из них.

## Выход из go-slides {#leaving-go-slides}

`slides expand` записывает каждый тип в виде точечных директив, которые он
обозначает, слайд за слайдом, так что результат — обычный Markdown для Marp,
который читает любой инструмент Marp.
