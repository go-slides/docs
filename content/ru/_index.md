**`slides` превращает презентацию Marp в готовую презентацию на чистом Go.** Он читает
Markdown, который читает [Marp](https://marp.app): директивы Marpit, `---` между
слайдами, фоны `![bg]`, заметки докладчика, темы `default`, `gaia` и
`uncover` — и добавляет две вещи, которых в Marp нет:

- **[шаблоны Go]({{< relref "templates" >}})** внутри презентации, вычисляемые
  до разбора Markdown, так что презентация может сама порождать свои слайды;
- **[типы слайдов (kinds)]({{< relref "kinds" >}})**: слайд говорит, чем он является
  (`title`, `section`…), вместо того чтобы повторять, как он выглядит.

## Что он умеет сегодня {#what-it-does-today}

| | |
| --- | --- |
| `slides build` (по умолчанию) | презентация в виде одной HTML-страницы: каждый слайд — `<section>` в SVG-рамке, масштабируемой под окно, CSS темы, просмотрщик с управлением с клавиатуры |
| `slides build --pdf`, `--images png`, `--image jpeg` | презентация в виде PDF (одна страница на слайд, с оглавлением) или изображений PNG/JPEG, без браузера: рисует [go-webengine](https://github.com/go-webengine), PDF пишет [go-pdfkit](https://github.com/go-pdfkit) — векторный начиная с v0.4.0, с выделяемым текстом: [Векторный PDF]({{< relref "cli#vector-pdf" >}}) |
| математика и код | `$…$` и `$$…$$` набирает go-tex/math, блоки кода подсвечивает go-rouge — в HTML, изображениях и PDF: [Математика и код]({{< relref "math-and-code" >}}) |
| эмодзи | `:smile:` и 😄 становятся изображениями Twemoji, встроенными, так что сеть не нужна и они рисуются в любом формате: [Эмодзи]({{< relref "emoji" >}}) (начиная с v0.4.0) |
| `slides build --pptx` | презентация в виде файла PowerPoint с заметками докладчика и метаданными: в v0.4.0 — по картинке на слайд, как в marp-cli; **редактируемая** начиная с v0.5.0 — текстовые блоки, фигуры, картинки, встроенные шрифты ([Редактируемые PPTX и ODP]({{< relref "cli#editable-pptx-and-odp" >}})) |
| `slides build --odp` | то же в виде презентации OpenDocument (`.odp`) |
| заголовки по ширине | `# <!-- fit --> Title` растягивает заголовок на всю ширину слайда в одну строку — на странице и в каждом экспорте |
| `slides expand` | презентация в виде обычного Markdown для Marp: шаблоны вычислены, типы заменены точечными директивами, которые они обозначают |
| `slides notes` | заметки докладчика |
| `slides kinds`, `slides themes` | то, что презентация может назвать по имени |
| `slides.yaml` | общие типы, темы, данные, политика HTML и язык для папки с презентациями |
| HCL | front matter `---hcl`, `slides.hcl`, файлы типов и данных в HCL2, с выражениями и функциями: [HCL]({{< relref "hcl" >}}) |
