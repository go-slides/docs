**`slides` перетворює презентацію Marp на готову до показу, на чистому Go.**
Програма читає той Markdown, який читає [Marp](https://marp.app): директиви
Marpit, `---` між слайдами, фони `![bg]`, нотатки доповідача, теми `default`,
`gaia` та `uncover` — і додає дві речі, яких у Marp немає:

- **[шаблони Go]({{< relref "templates" >}})** усередині презентації, що
  обчислюються до розбору Markdown, тож презентація може сама генерувати свої
  слайди;
- **[kinds (види слайдів)]({{< relref "kinds" >}})**: слайд сам каже, чим він є
  (`title`, `section`…), замість того щоб повторювати, як він виглядає.

## Що це вміє сьогодні {#what-it-does-today}

| | |
| --- | --- |
| `slides build` (типова команда) | презентація як одна HTML-сторінка: кожен слайд — `<section>` в SVG-рамці, що масштабується під вікно, CSS теми, клавіатурний переглядач |
| `slides build --pdf`, `--images png`, `--image jpeg` | презентація у вигляді PDF (одна сторінка на слайд, зі змістом) або зображень PNG/JPEG, без браузера: рендерить [go-webengine](https://github.com/go-webengine), PDF пише [go-pdfkit](https://github.com/go-pdfkit) — векторно починаючи з v0.4.0, з текстом, який можна виділяти: [Векторний PDF]({{< relref "cli#vector-pdf" >}}) |
| математика й код | `$…$` та `$$…$$` верстає go-tex/math, блоки коду підсвічує go-rouge — в HTML, зображеннях і PDF: [Математика й код]({{< relref "math-and-code" >}}) |
| емодзі | `:smile:` та 😄 стають зображеннями Twemoji, вбудованими, тож мережа не потрібна, і вони малюються в усіх виводах: [Емодзі]({{< relref "emoji" >}}) (починаючи з v0.4.0) |
| `slides build --pptx` | презентація як файл PowerPoint з нотатками доповідача та метаданими: одна картинка на слайд у v0.4.0, як у marp-cli; **редагована** починаючи з v0.5.0 — текстові блоки, фігури, зображення, вбудовані шрифти ([Редагований PPTX і ODP]({{< relref "cli#editable-pptx-and-odp" >}})) |
| `slides build --odp` | те саме у вигляді презентації OpenDocument (`.odp`) |
| заголовки за шириною | `# <!-- fit --> Title` заповнює ширину слайда в один рядок, на сторінці й у кожному експорті |
| `slides expand` | презентація як звичайний Markdown Marp: шаблони обчислено, kinds замінено на spot-директиви, які вони означають |
| `slides notes` | нотатки доповідача |
| `slides kinds`, `slides themes` | що презентація може назвати |
| `slides.yaml` | спільні kinds, теми, дані, політика HTML і мова для теки презентацій |
| HCL | front matter `---hcl`, `slides.hcl`, файли kinds і даних у HCL2, з виразами та функціями: [HCL]({{< relref "hcl" >}}) |

## Заплановано {#planned}

Ще не зроблено, і наведено, щоб нікому не доводилося гадати: формули у вигляді
векторів у PDF (там вони растрові). Відмінність від
marp-cli — у шляху: він рендерить зображення й PDF, керуючи headless Chrome;
тут це роблять бібліотеки Go.
