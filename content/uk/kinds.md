**Kind** (вид слайда) — це іменований набір локальних директив: колонтитул, нижній
колонтитул, нумерація, клас, фон. Слайд каже, чим він є — `title`,
`section` — замість того щоб повторювати, як він виглядає, і вигляд
презентації змінюється в одному місці.

## Використання kind {#using-a-kind}

```markdown
<!-- kind: section -->
# Part two

---

<!-- _kind: blank -->
![bg](photo.jpg)
```

- `kind:` застосовується як локальна директива: до цього слайда й наступних.
- `_kind:` застосовується як spot-директива: лише до цього слайда.
- Перемикання kinds спершу **скидає** те, що встановив попередній kind, тож
  клас чи нижній колонтитул ніколи не «витікає» з одного kind до наступного.
- Директиви, написані на самому слайді, **мають перевагу** над kind.

## Вбудовані {#built-in}

| Kind | Встановлює |
| --- | --- |
| `title` | `class: lead`, без номера сторінки, без верхнього колонтитула, без нижнього |
| `section` | `class: lead` |
| `content` | нічого: власні типові значення презентації |
| `blank` | без номера сторінки, без верхнього колонтитула, без нижнього |

Будь-який із них можна перевизначити.

## Визначення kinds {#defining-kinds}

У front matter:

```yaml
---
marp: true
kinds:
  chapter:
    class: invert
    backgroundColor: "#1e1b4b"
    paginate: false
  quote:
    extends: blank
    class: quote
---
```

`extends` починає kind з директив іншого. Kind приймає локальні директиви та
`extends`.

## Спільні kinds {#sharing-kinds}

Kinds команди варто тримати в одному файлі, який називає кожна презентація:

```yaml
# kinds.yaml
chapter:
  class: invert
  paginate: false
```

```yaml
---
marp: true
kinds: kinds.yaml        # or a list of files
---
```

або `--kinds kinds.yaml` у командному рядку, або `kinds:` у `slides.yaml`.
Порядок такий: вбудовані kinds, потім командний рядок і файл конфігурації,
потім власні `kinds:` презентації.

`slides kinds talk.md` виводить перелік kinds, які може використовувати
презентація, і що встановлює кожен із них.

## Вихід із go-slides {#leaving-go-slides}

`slides expand` записує кожен kind як spot-директиви, які він означає, слайд за
слайдом, тож результат — звичайний Markdown Marp, який читає будь-який
інструмент Marp.
